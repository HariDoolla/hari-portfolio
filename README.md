# Doolla Hari — Portfolio

Personal portfolio website built from resume data using React, Vite, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- Dark & light theme toggle (persists in localStorage)
- Fully responsive layout for mobile, tablet, and desktop
- Smooth scroll animations with Framer Motion
- Sections: Hero, About, Skills, Experience, Projects, Education, Contact

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Customize Content

Edit `src/data/resume.ts` to update your profile, experience, projects, and skills.

## Tech Stack

- React 19
- Vite
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React (icons)
